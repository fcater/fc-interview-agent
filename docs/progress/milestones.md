## 维护约定

1. **严格顺序推进**：按 [roadmap.md](../roadmap.md) 的 M0→M7 逐阶段开发，**上一阶段验收通过后才进下一阶段**（`CLAUDE.md` 硬性约定第 1 条）。
2. **验收通过后**：在表格末尾加一行（阶段 / 内容 / 日期 / 提交 / 状态），状态从「🚧 进行中」改为「✅ 已验收」。
3. **新增阶段（M8+）**：先在 `roadmap.md` 写清任务与验收标准，再在本表建行。若该阶段有需要留痕的设计取舍或验收证据，在本目录下新建 `<阶段号>-<主题>.md`，并在表格「内容」列链上——本目录就是这类文件的归属地。
